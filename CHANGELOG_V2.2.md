# v2.2.0 Changelog

## Added
- View Profile actions for lecturers and students.
- Printable receipt detail dialog.
- Archive and restore workspace.
- Owner-only permanent deletion with history protection.
- Global search.
- Filters across core data tables.
- Outstanding workspace.
- CSV export with formula-injection mitigation.
- Pagination controls.

## Preserved
- Owner setup flow.
- Multi-admin permissions.
- D1 schema and existing records.
- Lecturer renewals.
- Student enrollment and partial payments.
- Activity log.
- Smart auto refresh.
- Flaticon UIcons integration.

## Database
No schema migration is required for this release.
